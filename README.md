# ALUVA - Sitio Web Corporativo

## Descripción

ALUVA es un emprendimiento dedicado al diseño, confección y distribución de ropa de trabajo, vestuario corporativo y Equipos de Protección Personal (EPP).

Este proyecto fue desarrollado como parte de la asignatura Diseño Web y tiene como objetivo proporcionar una plataforma web corporativa que permita presentar la empresa, sus productos, catálogo digital y medios de contacto.

## Evolución del Proyecto

### Evaluación 1
Desarrollo de estructura HTML semántica y mockup inicial. 

### Evaluación 2
Incorporación de estilos CSS, diseño responsive y mejora visual del sitio. 

### Evaluación 3
Migración del sitio a una plantilla Bootstrap One Page y adaptación de contenido corporativo.
